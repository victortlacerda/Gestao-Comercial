Últimas atividades registradas

1. Importar a planilha atual

Carrega a aba PROPOSTAS do arquivo .xlsm/.xlsx e converte cada linha em uma proposta do app.

2. Ler PDFs das propostas

Lê os PDFs no próprio navegador e preenche contrato, CNPJ, contato, telefone, e-mail e obra. No computador, use “pasta de propostas” para aproveitar também o nome das pastas (cliente, cidade e serviço).

Propostas novas entram como Nova. Depois, em Propostas, selecione as que já foram enviadas ao cliente e use “Aplicar status → Enviada” para mover várias de uma vez. Em cada pasta o app usa só o PDF da proposta e, quando há revisões (… - Rev.01), lê a mais recente. As revisões continuam sendo a mesma proposta, então o total do ano não infla. Anexos como ART, contrato e memorial são ignorados.

Backup e restauração

O app guarda tudo no navegador deste dispositivo. Exporte o backup para levar os dados para outro celular ou computador — e para compartilhar com a equipe.

Importar JSON do extrator Python

Se você rodar o extrator em lote (pasta extrator/), ele gera um arquivo propostas.json. Carregue-o aqui para atualizar centenas de propostas de uma vez.

Limpar base

Remove todas as propostas e atividades deste dispositivo. Exporte um backup antes.
